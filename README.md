# RE:MAKE Banner Studio

사진·로고·카피를 조합하고 각 요소를 수정하는 한국어 광고 배너 웹앱입니다. API 호출이나 사용량 과금 없이 브라우저에서 작동합니다.

## 사용 흐름

1. 사진과 선택 로고를 업로드합니다. PNG/JPEG/WebP, 파일당 20MB까지 지원하며 최대 변 길이 2560px로 정규화합니다.
2. 메인/서브/버튼 카피, 브랜드명, 안내 문구를 입력합니다.
3. 포토 임팩트 / 스레드 스토리 / 클린 카드 중 스타일과 비율을 선택합니다. 한 번에 1~3개 스타일을 생성할 수 있습니다.
4. 캔버스에서 레이어를 선택하고 드래그·크기 조절하거나 오른쪽 속성에서 수정합니다. 색상, 문구, 글꼴, 크기, 정렬, 회전, 투명도, 사진 크롭/교체, 표시/잠금, 순서, 복제, 삭제를 지원합니다.
5. 베리에이션 탭에서 개별 비율 또는 전체 비율을 추가합니다. 원본 카피·사진·스타일은 유지하며 위치와 글자 크기는 새 비율의 템플릿에 맞게 재배치합니다. 각 결과는 독립적으로 수정됩니다.
6. 개별 PNG 또는 전체 ZIP을 내보냅니다. JSON 프로젝트 저장/열기로 편집 레이어를 보존합니다.

| 비율 | 출력 크기 |
|---|---|
| 1:1 | 1200×1200 |
| 16:9 | 1920×1080 |
| 9:16 | 1080×1920 |
| 1.19:1 | 1190×1000 |
| 4:5 | 1080×1350 |

프로젝트는 IndexedDB에 자동 저장됩니다. 브라우저 데이터를 지우면 삭제되므로 JSON 파일로 백업하세요. 작업은 기기 간 자동 동기화되지 않습니다. 프로젝트당 배너 50개, 배너당 레이어 100개, 실행 취소 30단계를 지원합니다.

## 현재 범위와 제한

- **AI 없는 템플릿 편집기**입니다. 자유 프롬프트 해석·이미지 생성·배경 확장·자동 레이어 분리는 포함하지 않습니다.
- 레퍼런스 이미지는 비교용으로 저장/표시됩니다. 별도 요청 사항은 제작 메모로 보존됩니다.
- 이미 완성된 이미지의 글자/로고는 사진의 일부입니다. 별도 레이어 편집을 위해 글자 없는 원본 사진과 로고를 넣어주세요.
- 베리에이션은 정해진 템플릿 기반 재배치입니다. 사진의 얼굴 위치를 AI로 인식하지 않습니다. 사진 크롭 슬라이더로 보정하세요.
- 스레드형은 소셜 포스트 분위기의 자체 레이아웃입니다. 실제 후기·참여 수치를 자동으로 만들어 넣지 않습니다.
- 안내 문구와 급여·혜택 조건은 사용자가 직접 입력합니다. 업로드된 광고 레퍼런스의 과거 금액을 자동 재사용하지 않습니다.
- PNG 렌더러는 운영체제의 한국어 글꼴을 기본 사용합니다. Noto Sans KR을 선택하면 Google Fonts 연결이 필요합니다.

## 로컬 실행 / 검증

Node.js 22 이상만 필요합니다. 런타임 의존 패키지는 없습니다.

```sh
npm run dev
npm test
npm run build
```

개발 주소: `http://127.0.0.1:4173`. 빌드 결과: `dist/`.

## Vercel 배포

Vercel에서 이 GitHub 저장소를 Import합니다.

- Framework Preset: Other
- Root Directory: 저장소 루트
- Build Command: `node scripts/build.mjs`
- Output Directory: `dist`
- Environment Variables: 없음

`vercel.json`에 빌드와 보안 헤더가 포함되어 있습니다. 서버리스 함수, 데이터베이스, API 키가 필요하지 않습니다. GitHub 연결 후 main 변경 시 자동 재배포할 수 있습니다.

**Vercel Hobby는 개인·비상업적 용도로 제한됩니다.** 무료 배포는 개인 프로토타입 검토용으로 사용하고 실제 광고 업무에 운영하려면 적합한 호스팅 플랜을 확인하세요. https://vercel.com/docs/plans/hobby

## 데이터와 API

사진/로고/카피는 서버로 전송하지 않습니다. 외부 요청은 웹폰트 로딩만 사용합니다. 원본 광고 이미지와 계정 토큰은 저장소에 포함하지 않습니다. 별도 인증 서버 없이 개인 브라우저 작업 공간으로 작동합니다.

AI를 붙일 때에는 이미지와 편집 레이어 데이터를 분리하고, 서버 측 OpenAI Platform API 키를 통해 레퍼런스 분석/배경 이미지 생성 기능을 추가할 수 있습니다. ChatGPT Business 구독 인증은 이 앱의 일반 이미지 API 키로 재사용하지 않습니다. 현재 버전에는 AI 호출 코드와 키 입력창이 없습니다.

## 참고한 방향

- 사용자가 제공한 CLS 광고: 실사·굵은 카피·강조색 CTA, 소셜 포스트, 화이트 카드 레이아웃.
- AdCreative.ai 공개 소개: 브랜드 애셋 입력 → 포맷 선택 → 생성 흐름. https://www.adcreative.ai/
- Variaid 공개 소개: 한 시안의 여러 사이즈 미리보기 → 편집 → 일괄 다운로드 흐름. https://variaid.com/ko

외부 서비스의 소스나 비공개 화면을 복제하지 않았으며 기능·성과 주장을 차용하지 않습니다. PSD 가져오기는 지원하지 않습니다.
